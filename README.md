# AI指挥官企业版——如何成为FDE？

> 从会用AI，到在企业现场把AI项目做成。

这不是一本工具说明书，也不是一份“速成FDE”的职位攻略。它写给正在承担企业AI落地任务的人：你可能来自业务、技术、产品、咨询、培训或管理岗位；你的共同任务，是进入真实现场，把模糊期待变成可验证结果。

全书由两张地图组成：上篇“九段”回答一个人如何从结构化使用AI，成长为能够组织人机协同和决策系统的AI指挥官；下篇“企业战略罗盘”回答进入企业以后，应该从哪里发现问题、怎样理解销售与产品两条业务轴，以及如何检查战略、管理和外部关系条件。

## 这本书怎样使用

第一次接触企业AI落地，建议从导论开始顺序阅读上篇；已经在承担项目，可以先读第10章定位业务节点，再回到上篇补能力；正在组织企业转型，可以重点阅读第13至16章，并用附录模板跑一次小范围试点。

本书的最小验证不是“读完”，而是完成一张FDE任务一页纸，并让业务负责人确认：问题真实、边界明确、结果可以验收。

## 开放共建

我们优先接收真实、可复现、可说明边界的企业AI实践。贡献内容需要写明场景、输入、过程、权限、安全边界、失败处理、实际结果和验收标准。请先阅读[贡献指南](CONTRIBUTING.md)。
